## RIG + ACTION FORMAT SUMMARY (for re-skinning in a new style / size)
Pipeline: parts (char-maps) -> actions_src/<act>.py keyframe tables -> tools/build.py -> actions/<act>_<DIR>[_ns].json -> tools/compose.py -> frames/, sheets/, gifs/ ; tools/qc.py runs after every build.
1. Parts: plain-text char-maps (tools/cm.py; palette v2/pixel/palette.json + VFX x w y Y o; '.' transparent). Meta: '; pivot X Y' (where the part attaches), '; anchor NAME X Y' (child attach points, may be outside the grid). Integer placement only, no rotation/resampling at runtime -> every angle/pose is a pre-drawn part. Dirs: parts/se/ (SE body parts, ~400 files incl. per-action prefixed <act>9_/<act>10_ variants), parts/common/ (katana kat_00..15 = 16 dirs, 00=E 04=up 08=W 12=down CCW, pivot=grip; FX smears/sparks/dust/ghosts). Backups: parts/se_preD2, se_preR5, common_preR10.
2. Rig (actions/stand_SE.json; any direction D uses actions/stand_<D>.json + parts/<d>/): legs(pivot = ground centre, anchor hip, z1) <- skirt(pivot top, anchor waist, z3) <- torso(anchors neck shL shR waist, z4) <- head(pivot = neck point under chin, anchors bow bun, z7) ; bun(z0, at head.bun) ; bow(z8, at head.bow) ; armN near/sword sleeve (pivot shoulder, anchor hand = grip, z6, at torso.shL) ; armF far sleeve (z2, at torso.shR) ; kat (at armN.hand, z5 front / z1 behind). Cell 64x64 ground (32,60) default; per-action cells via CELLS (jump 76x80 g(40,76), dash 72x76, slash 92x76). Feet pivot aligns all cells.
3. Keyframe tables (tools/build.py docstring): F(ms, label, legs=, aN=, aF=, torso=, skirt=, head=, bow= (part names), root=(dx,dy) whole-body offset, tor/hd/bw=(dx,dy) part offsets, zN= near-arm z, kat=(dir, z[, (dx,dy)]) or None, fx=[(part,dx,dy,z[,attach])], ghosts=[{src:'self'|frame, off, ch, outline, dither}], shake, px=[[x,y,ch]] per-frame pixel edits rel. ground, shadow=bool|int half-width). Any key + '_ns' overrides it for the no-katana build. Module: ACTIONS={name:(frames, also_ns)}, optional CELLS, DIR.
   Modules: actions_src/{idle,walk,run,jump,dash,slash}.py (one per action; old combined modules in work/old_src/).
4. Timing (ms tables live in the modules; current): idle 11-13f two-breath loop 100-220ms with blink on 2nd breath; walk 8f contact120/down100/pass80/up100; run 8f ~60-90 (contact/down/push/air x2); jump antic->deep crouch 140->launch 50->rise->apex->hang->fall->land 130->recover->rebound->settle; dash antic 110 -> burst 40/50 (solid 2-tone afterimage + speed lines) -> skid 90 -> brake 70 -> settle -> rest; slash ready->antic->lift->wind->coil 120->swingA 30->SMEAR 40->impact 40 (flash/spark)->hitstop 60+50 (frozen pose, +-1px shake)->follow->pass->recover->settle->rest.

FX structure: smear = 2-3 frame sweep emitted from the blade path (swingA, SMEAR, impact trail), generated by work/r12/smear12.py (rebuild slash with SLASH_NOSMEAR=1 first, it reads the blade geometry); dash afterimage = solid 2-tone silhouette fx parts (fx_dash10_ghost*) or composer ghosts {src:'self'}; dust/land puffs as fx at 'ground' z0.5 (never over boots); sparks anchored at armN.hand.
6. QC tools/qc.py: per frame, head part bbox vs rig head (>1px = FAIL), off-palette chars, hidden head/bun. Ref head = rig 'head' part, so swapping head.txt re-baselines it.

## FRAME-BY-FRAME HARNESS (style round, Pokemon C-48)
Tools (v2/anim_cut/tools; python = /Users/waylonhuang/Documents/other/pixelart/swordswoman/.venv/bin/python):
- ff_redraw.py stamp MASTER.txt OUT.txt --rows Y0 Y1   cut the locked head+face stamp (e.g. ff/stamps/C_r3_SE_head.txt = C_r3 rows 14-37). Swap for the locked master's stamp when it exists.
- ff_redraw.py prep ACT DIR --guides GDIR [--ms 120,80,..] [--poses pose/poses.json --stamps ../masters/heads (per-frame expression stamp + KEY INTENT/blade arc in prompt)] [--cell 64 64] [--pivot 32 61] [--gpivot 48 88] [--gscale 4]
  GDIR = v2/hy3d/frames/<act>_<dir>/ (or keys_parts/<act>_<dir>/) with fNN_matid.png (+keys.json for key names). Box-mode downsample to 1x, material colours -> nearest pk char, standing frames snapped so the lowest row = pivot row; key names with apex/rise/fall/air/launch/hang = airborne ('; air' meta). Writes ff/<ACT>_<DIR>/gNN.txt, gNN_1x/_4x/_sil.png, frames.json (edit ms/air there if needed).
- ff_redraw.py draw ACT DIR --master M.txt --stamp S.txt [--frames 0,3] [--jobs N] [--accounts bni_requests,nsystem4,be_system] [--key0] [--retries 2]
  Per frame: prompt pNN.txt = guide char-map inline + 4x/silhouette/original render paths + style master + head stamp + palette legend + STYLE_GUIDE §5/§6/§10 (O1-O3, S1-S5, face, R1-R6) + prev/next frame (drawn if present, else guide). Artist (claude-as, Opus 5.5) writes fNN.txt itself and self-runs lint_style. Harness validates (size, lint, POSE IoU >= 0.5 vs guide) and sends the fix list back automatically (max --retries). --key0 draws frame 0 first so the others get it as continuity; then the rest run in parallel, accounts round-robin. Logs logNN.txt, lintNN.txt. Retries on API/proxy errors.
- ff_redraw.py assemble ACT DIR [--stamp S]  -> ff/<ACT>_<DIR>/<ACT>_<DIR>.gif (6x, #6e6e6e, per-frame ms), sheet.png (guide | frame pairs, <=1000 px), lint.txt.
- ff_redraw.py all ACT DIR --guides .. --master .. --stamp .. [--jobs N] = prep + draw --key0 + assemble.
- lint_style.py f.txt.. [--stamp S] [--pivot X Y] [--air] [--json]: PAL (palette-only, <=16 colours), O1 (edge pixels K), R1 (no K inside except lash/pupil face box, 2px soles, hair underside, chin line), O3 (1-3-1 contour jaggies), S4 (orphans, except W/n/K/eyes), HEAD (stamp eyes+lash pixel-identical, head width +-1), FEET (lowest row = pivot unless '; air', feet centre +-8 px). Exit 1 + fix lines on failure.
