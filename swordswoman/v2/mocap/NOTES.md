## Timing / key-selection rationale (keys at true mocap extremes; game timing from PMD AnimData + STYLE_GUIDE 8)
- idle (Bandai1 slash_normal_001 guard 138-162, chudan guard): the only real idle-like data is the settle into guard; ping-pong 138->162->138 with the real micro-motion x8 about the guard (1-2 px breath, blade tip lags), long holds on up/down_hold (300 ms) like PMD's 40-60-tick idle hold. Blade tip lowered 20 deg, torso turned toward the camera.
- walk (Bandai1 walk_active cycle 58-90, 1.07 s real): contact = heel strike, down = pelvis minimum 3 f later, pass = ankles crossing (pelvis max), both sides; real cycle compressed to 650 ms (110/100/110), stride/arm swing x1.45 about the cycle mean, stance foot locked on a treadmill (constant slide = game move speed).
- run (CMU 09_01 cycle 43-131 @120 fps, 0.73 s -> 440 ms): contact (80, longest like Gen3 5/3 ticks), pass/down, air at toe-off (68/112: back leg fully extended); swing x1.7, +20 deg lean, flight x2.2, blade trailing back-up.
- jump (CMU 16_03 high jump): antic = start of dip (126), crouch = pelvis min (153), launch = toe-off (181, 50 ms snap), rise, apex = pelvis max (216, 160 ms hold), fall, land = squash min (266, 140 ms), recover; real 1.4 s -> 830 ms (crouch compressed, apex held, as PMD Hop eases into the apex hold); crouch x1.9, apex tuck x2.4, height x2 (~16 px, stays in the 64 cell; extra height belongs to game code).
- dash (CMU 143_03 start-to-run + 127_05 run-to-quick-stop): antic = lean-in (160), burst/smear = drive steps (180/200, 40 ms each, no crescent - speed lines are VFX), skid = front foot planted, body upright (96), recover (230); drive x1.4-1.6 + 22 deg lean.
- slash (Bandai1 slash_normal_002 rising diagonal cut): antic = guard raise (28, 160 ms), windup = high cocked blade over the shoulder (36, 100 ms = PMD 4-6 tick hold before the hit), smear = fastest frame (59, 40 ms, crescent), impact = blade extended forward-up (62, 140 ms hit-stop), follow (65, 80), recover/settle = return to guard (102/126; real 25-frame zanshin hold cut); x1.3 about the guard, root x0.5 so the arc stays in the cell.
- overhead (Bandai1 slash_normal_001 vertical cut): antic (176), raise = top of the lift (196, 150 ms hold), smear (206, 40), impact = blade at the bottom of the chop (212, 160 ms hit-stop, tip +25 deg down), follow (218), recover (240); raise x1.8 + slight back-arch, impact x1.4 with pelvis drop x3.
- hurt (LaFAN1 pushAndStumble1_subject5 548-600, pushed from the front): hit = jolt (553, 80 ms ~ PMD 2-tick flash made readable), recoil = arms flung + lean back (558, 110), stagger = step back (568, 160 = PMD 8-tick hold), recover (588); reaction x2, knockback x0.35.
